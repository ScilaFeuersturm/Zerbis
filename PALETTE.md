# Zerbis palette base

Mantener esta paleta como base visual para próximas vistas de la aplicación Zerbis:

- `#2A7BDE` (azul principal)
- `#4C2ADE` (violeta intenso)
- `#2A42DE` (azul cobalto)
- `#2AB4DE` (aqua)
- `#872ADE` (púrpura)
- `#A2AAE1` (lavanda suave)

Aplicación sugerida:
- Colores de acento y acciones primarias: `#2A42DE`, `#2A7BDE`.
- Gradientes/branding: combinaciones con `#4C2ADE`, `#872ADE`, `#2AB4DE`.
- Fondos suaves y superficies secundarias: `#A2AAE1` con opacidades.
